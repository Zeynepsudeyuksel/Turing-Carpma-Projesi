# İkili Sayı Çarpma Turing Makinesi

## Proje Hakkında
Bu proje, **Özdevinirler Kuramı** dersi kapsamında geliştirilen, tek bantlı bir Turing Makinesi simülasyonudur. Program, ikili (binary) tabanda verilen iki sayıyı "kaydır ve topla" (shift & add) algoritması ile çarpmaktadır.

## Kullanılan Teknolojiler
* Python 3.x

## Nasıl Çalıştırılır?
1. Bilgisayarınızda Python yüklü olduğundan emin olun.
2. Terminali veya komut istemini açın.
3. Dosyanın bulunduğu dizine gidin.
4. Şu komutu çalıştırın: `python turing_makinesi.py`
5. İşlem için `11*10=` formatında bir girdi girin.
